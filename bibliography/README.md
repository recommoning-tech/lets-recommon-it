# Annotated Bibliography

One file per source, named `author-year-short-title.md`. Start from [`../templates/bibliography-entry.md`](../templates/bibliography-entry.md).

- `threads` tags match [`../planning/concept-map.md`](../planning/concept-map.md).
- `status: draft` means the annotation has not been reviewed by the author yet.
- Sources still to add are listed in [`../planning/reading-list.md`](../planning/reading-list.md).
