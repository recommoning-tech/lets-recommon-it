# The table

Let's Recommon IT is organized as a table. Each row is a thread (defined in [`planning/concept-map.md`](planning/concept-map.md)). Each column is a level of rules from Elinor Ostrom's institutional analysis, explained in [This repository is a commons](theory/this-repository-is-a-commons.md).

Any cell can be filled at any time, and a cell can hold more than one piece. Open cells are invitations. See [Writing for Let's Recommon IT](guides/contributing.md) to contribute.
